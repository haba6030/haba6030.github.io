\cvsection{Research Experiences}
\cventry[8]\orgrow{Connectome Lab}{Seoul National University}
\rolerow{Undergraduate RA \ \ (Advisor: Prof.\ Jiook Cha)}{Apr 2025 -- Present}
\begin{itemize}
  \item Led a project characterizing distortions of cortical hue geometry in color vision deficiency from fMRI. Translated them into personalized filters that moved hue-discrimination thresholds to the control range.
  \item Leading uncertainty evaluation of generative EEG foundation models, showing that distributional scores catch distortions that point metrics miss and that seed variance can flag unreliable channels.
  \item Training brain foundation models with literature-derived priors via text alignment or by using each region's functional profile as its positional encoding.
\end{itemize}
\vspace{0.90em}

\cventry[5]\orgrow{Computational Clinical Science Lab}{Seoul National University}
